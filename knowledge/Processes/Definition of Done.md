# Definition of Done

A story is done when:
- It works end to end in a demo environment.
- Acceptance criteria from the brief are met and cited to the clause (e.g. [[SPL Brief v2 Changes]]).
- Automated tests pass; QA ([[Nurul Izzah]]) has reviewed critical flows.
- Personal data follows [[PDPA]] and policy SEC-4 (no ICs in logs, chat or email).
- Access is enforced in backend code, not only in the UI.
- Docs updated; the PM has accepted it ([[Change Request Process]] for any scope change).
