# New joiner onboarding checklist

- [ ] Enable MFA on email, source control and the HR system (policy SEC-2).
- [ ] Read client-document rules (SEC-1): client files stay on the ATOM; never use public AI tools.
- [ ] Read PDPA rule SEC-4: never share IC numbers in chat or email.
- [ ] Know incident reporting: tell DevSecOps ([[Arjun Pillai]]) within 24 hours (SEC-3).
- [ ] Project access is need-to-know (SEC-5): you see only assigned projects, so you will see none on day one.
- [ ] Learn leave rules: [[Leave Guide]] (LV-1 to LV-5).
- [ ] Learn expense rules: [[Expense Claims Guide]].
- [ ] Meet [[Daniel Tan]]; ask HR ([[Office Roles - Finance HR Exec]]) about the rest.
- [ ] Skim [[Home]] and [[Staff Directory]].
